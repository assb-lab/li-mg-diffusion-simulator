# Docs Index

## SSOT Rule

この `docs/` ディレクトリが製品仕様と開発仕様の恒久的SSOTである。

`AGENTS.md` は開発ルールを扱うが、製品要求・機能設計・API定義・ディレクトリ詳細・開発作業手順は `docs/` を正とする。
