# .steering

`.steering/` は各実装イテレーションの作業記録を置く場所である。

恒久的な仕様の正本ではない。
仕様として残すべき内容は `docs/` に昇格する。

---

## File Naming

```text
NNNN-short-name.md
```

Example:

```text
0001-documentation-bootstrap.md
0002-project-bootstrap.md
0003-diffusion-core-solver.md
```

---

## Rule

1 iteration = 1 steering file = 1 commit
